Simple and fine-tuned OpenCore EFI folder for **macOS 15 Sequoia**. 
## Hardware
- **CPU:** AMD Ryzen 7 Pro 1700X
- **GPU:** AMD Radeon RX 5700 XT
- **Motherboard:** Socket AM4 (X370)

## ⚠️ Important Warning
- **Kexts:** Some kexts are currently **disabled** in `config.plist` .
- **SMBIOS:** Internal serial numbers are cleared for security. Generate your own SMBIOS before boot!
